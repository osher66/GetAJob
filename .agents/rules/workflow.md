# Workflow & Language Rules

- **Interaction**: The user communicates in Hebrew. Final status summaries and explanations must be in clear, concise Hebrew with proper RTL alignment.
- **Internal Reasoning & Code**: All internal reasoning, tool calls, terminal commands, code, git messages, and technical comments must remain strictly in English.
- **Response Structure**:
  - **Status / Explanation (עברית)**: Short, bulleted summary of what was done or needed. No conversational filler or pleasantries.
  - **Code / Actions (English)**: The actual code or commands directly, without repeating explanations inside the code.
